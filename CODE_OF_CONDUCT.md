# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be kind, be constructive, assume good faith, and keep the game's own rule — every round
is against the arena, never against another player.

Unacceptable behaviour can be reported to the maintainer at <prashant101007@gmail.com>. Reports are
handled privately and promptly.
